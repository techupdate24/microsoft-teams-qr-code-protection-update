# Microsoft Teams Rolls Out QR Code Protection

![Banner](banner.jpg)

To combat the rising threat of 'Quishing' (QR Code Phishing), Microsoft is deploying new advanced protection features within Microsoft Teams. This highly anticipated security update utilizes Defender for Office 365 integrations to actively scan, analyze, and block malicious QR codes shared in chats and channels before they can compromise employee credentials or deploy mobile malware.\n\nOur latest enterprise security briefing details how the new Teams QR protection works, the mechanics of modern Quishing attacks, and how IT administrators can configure these defenses across their tenant.\n\nRead the full technical breakdown on our official security portal.
